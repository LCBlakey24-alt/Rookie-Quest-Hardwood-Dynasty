# UI Design Parity Audit

This document compares Hardwood Dynasty's current visual/game-feel direction against the standard expected from a premium sports management game.

It exists to stop future UI work becoming random dashboard polish. Every visual change should move the project closer to a complete management-game interface.

## Honest Current Rating

Current visual level: promising prototype.

Target visual level: premium sports management game.

The current UI is not yet on par with Football Manager or other mature management games.

It has useful structure and several good ingredients, but it still looks and behaves more like a polished browser dashboard than a complete Steam-ready sports management game.

## What Already Works

The current direction has strong foundations:

- Dark command-centre theme.
- Clear sidebar navigation.
- Cards and panels for manager information.
- Team colour support.
- Team logo support and fallback crests.
- Dashboard summary cards.
- Manager inbox concept.
- Match centre/results screens.
- League table and playoff screens.
- Display density options.
- Focus mode for My Team vs League.
- Intro/landing screen direction.

These are good foundations for a basketball management sim.

## Where It Falls Short

### 1. It still feels like a website in places

Many screens are currently:

- Panel grid.
- Text block.
- Button.
- Table/list.

That is functional, but it does not yet feel like a full sports-management game interface.

Needed improvement:

- More screen identity.
- More game-specific layouts.
- Fewer generic card grids.
- More club office, coaching board, scouting room and matchday presentation.

### 2. The dashboard needs stronger hierarchy

The dashboard should feel like the manager's daily home base.

Current issue:

- Many panels compete for attention.
- Some sections feel equally important.
- The next key decision is not always visually dominant.

Needed improvement:

- One primary command card.
- One urgent task stack.
- One compact team status strip.
- Better separation between matchday, squad, board and save controls.

### 3. The landing screen is not yet Steam-quality

The landing screen has direction, but it needs to become a proper game main menu.

Needed improvement:

- Stronger title treatment.
- Continue Career, New Career, Load Save and Settings as primary menu actions.
- Background treatment that feels like a basketball operations game.
- Version label.
- Save status panel.
- Better visual identity for Rookie Quest / Hardwood Dynasty.

### 4. Tables need to feel designed

Management games rely on tables, but they cannot look like raw HTML tables.

Needed improvement:

- Sticky headers where useful.
- Clear row hover/selection state.
- Better column spacing.
- Team logo/short name consistency.
- Sort/filter controls.
- Status badges.
- Compact mode readability.

### 5. Screens need more game moments

Football Manager feels alive because of moments:

- inbox news
- team talks
- matchday
- scouting reports
- press-like feedback
- board reactions
- player concerns

Hardwood Dynasty needs equivalent moments:

- match preview
- pre-game staff report
- post-game consequence report
- board reaction
- player concern
- injury update
- contract meeting
- offseason ceremony

### 6. Team branding needs more weight

A sports game lives through club identity.

Needed improvement:

- Team colour accents used more consistently.
- Team crest placement on screens.
- Arena/fan culture integrated into club pages.
- Rivalry styling.
- Trophy/history panels.

## Football Manager Comparison

Football Manager's UI succeeds because it is dense but purposeful.

It gives the player:

- A clear inbox flow.
- Strong navigation hierarchy.
- Detailed tables.
- Context-sensitive reports.
- Multiple ways to reach the same decision.
- Strong save/career structure.
- A world that reacts to the player's choices.

Hardwood Dynasty currently has pieces of this, but not the full presentation or depth yet.

The closest current strength is the management structure.

The biggest current weakness is presentation maturity.

## Recommended Visual Direction

Use the existing direction, but mature it into Midnight Broadcast.

Core style:

- Deep navy/black background.
- Basketball orange for primary actions.
- Broadcast blue for data/scouting.
- Championship gold for history, playoffs and prestige.
- Team colours as local accents.
- Clean high-contrast text.
- Dense but readable layouts.

Avoid:

- Generic SaaS dashboard patterns.
- Too many equal-weight cards.
- Random neon effects.
- Over-animated mobile screens.
- Raw tables without styling.

## Screen Redesign Priorities

### Priority 1: Main Menu

Goal: make the game feel like a game before the player enters a save.

Needed:

- Continue Career.
- New Career.
- Load Save.
- Settings.
- Version/build label.
- Save status.
- Strong branded background.

### Priority 2: Dashboard

Goal: create a true manager home hub.

Needed:

- Next match command card.
- Staff recommendations.
- Board pressure card.
- Squad condition strip.
- Recent result card.
- Save controls moved lower or into menu.

### Priority 3: Matchday Flow

Goal: make fixtures feel like events.

Needed:

- Pre-match preview.
- Win probability/matchup label.
- Lineup/rotation warning.
- Sim transition.
- Post-match report.

### Priority 4: Roster and Tactics

Goal: make squad decisions feel more hands-on.

Needed:

- Better player rows.
- Attribute mini-bars.
- Status badges.
- Rotation board view.
- Starting five visual layout.

### Priority 5: Offseason

Goal: make season rollover feel like a major game phase.

Needed:

- Season recap.
- Champion spotlight.
- Player ageing report.
- Contract expiry report.
- Development/regression summary.
- Start next season button.

## Steam Visual Readiness Checklist

Before Steam packaging, the game needs:

- Proper main menu.
- Save/load screen.
- Settings screen.
- Better loading/transition states.
- Clear version label.
- Consistent title/logo treatment.
- Branded icon and capsule art.
- Polished screenshots.
- Better first-time player onboarding.
- Full game loop visible in UI.

## Final Verdict

Hardwood Dynasty is not visually on par with Football Manager yet.

It is on the right road, but it is currently closer to an advanced browser prototype than a finished Steam management game.

The right next move is not random restyling. The right next move is to redesign the key game surfaces in this order:

1. Main Menu.
2. Dashboard.
3. Matchday Flow.
4. Roster/Tactics.
5. Offseason.

Each redesign should make the player feel like they are managing a living basketball club, not browsing a website.
